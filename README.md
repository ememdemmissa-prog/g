# Goblin Mod

Forge 1.20.1 (47.x) + GeckoLib 4.8.4+. Adds the Goblin Thief.

## Features

- **Stealing.** A goblin hit steals a random item from your inventory, then the goblin runs away for 20–40 seconds.
- **Greed.** Goblins run to items lying on the ground within 12 blocks and pocket them. A goblin never despawns while carrying loot.
- **Payback.** Killing a goblin drops everything it stole, plus gold nuggets (affected by Looting) and sometimes an emerald.
- **Natural spawns.** Single goblins spawn in forests, taigas, savannas, plains, meadows and swamps.

## Build

```sh
./gradlew build   # -> build/libs/goblinmod-<version>.jar
```

Requires JDK 17.
